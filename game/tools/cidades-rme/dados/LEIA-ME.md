# Dados do Remere's Map Editor

Os pincéis (`grounds.xml`, `borders.xml`, `walls.xml`, `doodads.xml`, `trees.xml`, `grass.xml`, `stones.xml`, `plants.xml`, `flowers.xml`) e as
tabelas de vizinhança (`brush_tables.cpp`) são do Remere's Map Editor da opentibiabr
(https://github.com/opentibiabr/remeres-map-editor — `data/materials/brushs/` e `source/brush_tables.cpp`), licença GPL-3.0.
São usados só pela ferramenta `tools/cidades-rme/` (não vão para o jogo): os ids dos itens do editor são os mesmos dos sprites capturados.
