# Skills do Draevor Idle

Cada pasta é uma skill do Claude Code (`<nome>/SKILL.md` + `references/` quando precisa). Elas apontam para o código e os documentos
reais do repositório em vez de copiá-los. Validar depois de mexer: `python3 .claude/skills/validar.py`.

| Skill | Objetivo | Arquivos relevantes | Depende de |
|---|---|---|---|
| `draevor-architecture` | onde cada regra mora, direção das dependências, server authority, modo/feature flags, legado, checklist antes de criar sistema | `game/backend/index.mjs`, `game/systems/itens-poe/{iniciar,catalogo}.mjs`, `game/systems/personagem/legado.mjs`, `references/mapa-do-repositorio.md`, `docs/migracao-poe-oficial.md` | — (é a base) |
| `draevor-engine` | relógio, tique, estado, instância, terreno, caminho, monstros, sala, quadro, offline, threads, persistência | `game/websocket/{sessao,quadro,limites}.mjs`, `game/systems/cacadas.mjs`, `game/systems/hunt/*`, `game/systems/simulacao-offline*.mjs`, `game/systems/server-save.mjs`, `docs/auditoria-performance.md` | architecture |
| `poe-combat` | pipeline de dano real, ficha, acerto/crítico/resistência/armadura/ES, afecções, cargas, golpe do monstro | `game/systems/hunt/combate.mjs`, `game/systems/acoes.mjs`, `game/systems/combate/*`, `game/systems/ficha.mjs`, `game/systems/itens-poe/{mods-poe,afeccoes,cargas,condicoes-poe,traduzir}.mjs`, `references/pipeline-real.md` | architecture, engine, itemization (mods), gems (skills) |
| `poe-itemization` | definição × instância da peça, geração, sockets, requisitos, equipar, mochila, moedas, validação | `game/gamedata/itens-poe/{catalogo-itens,regras,traducao}.json`, `game/systems/itens-poe/{jogo,gerar,sockets,moedas,so-itens-do-poe}.mjs`, `game/systems/itens/{item,equipamento}.mjs`, `game/systems/inventario.mjs` | architecture, loot (quando gerar), combat (efeito na ficha) |
| `poe-gems` | gema ativa/suporte: dado → interpretador → registro → instância no socket → suporte ligado → barra | `game/gamedata/itens-poe/{gemas-poe,suportes-poe}.json`, `game/systems/itens-poe/{gemas-poe,suportes-poe,compilador-de-gemas/}`, `game/systems/skills/gemas.mjs`, `game/engine/sockets-de-gema.mjs`, `game/systems/acoes.mjs` | itemization (sockets), combat (dano da skill) |
| `poe-loot` | o que cai e como: quantidade, raridade, base, mods, moedas, ouro, tabelas, pináculo, party, filtro, offline | `game/systems/hunt/combate.mjs` (`matarMonstro`, `vitoriaNoBoss`), `game/systems/itens-poe/{jogo,moedas,drops-por-monstro,pinaculos}.mjs`, `game/systems/{bolsa,afixos,bau,cacadas}.mjs` | itemization (geração), campaign (missão), engine (morte) |
| `poe-campaign` | atos, áreas sobre mapas do Draevor, cidades, objetivos, chefes, portal, progressão, editor de atos | `game/gamedata/itens-poe/campanha-poe.json`, `game/gamedata/atos/poe-ato-*.json`, `game/systems/itens-poe/{campanha,monstros,habilidades,pinaculos}.mjs`, `game/systems/campanha.mjs`, `game/admin/atos.mjs` | engine (instância, terreno), loot, gems (missões) |
| `draevor-testing` | rodar, escrever e classificar testes (A–E), fixtures, modos, banco, determinismo, por domínio | `game/testes/apoio*.mjs`, `game/testes/*.test.mjs`, `docs/migracao-poe-matriz.md` | todas (cada skill aponta os seus testes) |
